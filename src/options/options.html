Good to know

  • Shortcuts never fire while you are typing in a compose window, a reply, the search box or any other text field.
  • means on this computer. Settings sync across your browsers, so a shortcut set on a Mac uses Ctrl on Windows and Linux.
  • Undo clicks the Undo link Gmail shows after an action, so it works for as long as Gmail offers it.
  • Some actions (star, reply, newer/older, and others) use Gmail's own keyboard shortcuts behind the scenes. If one does nothing, turn on Settings → See all settings → General → Keyboard shortcuts on in Gmail.
